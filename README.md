# ESP32 IoT Server Workspace

Welcome to your ESP32 IoT Server project workspace!

The complete project code is located inside the [`esp32_iot_server/`](./esp32_iot_server/) directory.

### Quick Start
1. Open terminal in VS Code (`Ctrl + ~`).
2. Run:
   ```powershell
   cd esp32_iot_server
   python -m venv venv
   .\venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   python server.py
   ```
3. Open `http://localhost:5000` in your web browser.

For complete documentation, wiring examples, Arduino code, and step-by-step instructions, see the [Full Project README](./esp32_iot_server/README.md).
